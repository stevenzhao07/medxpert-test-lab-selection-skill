# 第三方检测项目清单 · 按产品类型

> 不同产品的检测项目差异很大，对照这个清单看有没有漏。

---

## 一、通用检测项目（所有产品都可能涉及）

| 类别 | 标准/项目 | 适用产品 |
|------|----------|---------|
| 电气安全 | IEC 60601-1 / GB 9706.1 | 有源器械 |
| 电磁兼容 | IEC 60601-1-2 / YY 0505 | 有源器械 |
| 生物相容性 | ISO 10993 / GB/T 16886系列 | 接触人体 |
| 性能测试 | 产品专用标准 | 所有产品 |
| 灭菌验证 | ISO 11135 / 11137 / 17665 | 无菌产品 |
| 货架期 | 加速老化/实时老化 | 无菌产品 |
| 包装运输 | ASTM D4169 / GB/T 4857 | 所有产品 |
| 软件测试 | YY/T 0664、IEC 62304 | 含软件产品 |
| 网络安全 | YY/T 1843 | 联网/软件产品 |

## 二、生物相容性检测（ISO 10993）

按接触部位和接触时长选项目：

| 接触类型 | 接触时长 | 常见检测项目 |
|---------|---------|-------------|
| 表面接触-皮肤黏膜 | 短期（<24h） | 细胞毒性、致敏、刺激 |
| 表面接触-黏膜 | 长期（>24h，<30天） | 加：急性全身毒性、亚急性 |
| 外部接入-血液 | 短期/长期 | 加：溶血、凝血、补体 |
| 植入-组织/骨 | 长期（>30天） | 加：植入、慢性毒性、遗传毒性 |
| 植入-血液 | 长期 | 加：全部上述项目 |

### 标准清单

- ISO 10993-1 评价与试验
- ISO 10993-5 体外细胞毒性
- ISO 10993-10 刺激与致敏
- ISO 10993-11 全身毒性
- ISO 10993-17 可沥滤物
- ISO 10993-23 刺激试验（替代旧版）

## 三、有源设备常见检测

### 电气安全（IEC 60601-1 / GB 9706.1）

- 通用要求
- 并列标准：60601-1-2（EMC）、1-3（辐射）、1-6（可用性）、1-8（报警）、1-9（环境）、1-11（家用）
- 专用标准：如 60601-2-XX（心电图机、监护仪、除颤仪等）

### 软件（IEC 62304）

- 软件安全级别（A/B/C）
- 软件生命周期文件
- 软件描述文档
- 软件验证确认

### 可用性（IEC 62366）

- 可用性工程文档
- 形成性评价、总结性评价

## 六、选检测机构的资质要求

### 中国NMPA注册检测

| 资质 | 要求 |
|------|------|
| **CMA** | 中国计量认证，强制，报告有法律效力 |
| **CNAS** | 中国合格评定国家认可委员会，推荐 |
| **医疗器械检验资质** | 该机构被认定为医疗器械检验机构 |
| **标准在授权范围内** | 检测机构的资质范围要覆盖你要测的标准 |

### 美国FDA

| 资质 | 说明 |
|------|------|
| ILAC-MRA | 国际实验室认可互认 |
| ISO 17025 | 实验室能力认可 |
| FDA认可的第三方（510(k) Third Party） | 部分产品可走第三方审评 |
| 企业自测 | 部分标准允许企业自己测试（要有质量体系） |

### 欧盟MDR

| 资质 | 说明 |
|------|------|
| ISO 17025 | 实验室能力认可 |
| 公告机构认可 | 部分关键测试要NB认可的实验室 |
| ILAC-MRA | 互认 |

## 七、费用周期估算

| 产品类型 | 检测费用（参考） | 周期 |
|---------|----------------|------|
| 一类简单器械（如手术器械） | 1-5万 | 1-2个月 |
| 二类无源器械（如骨科、耗材） | 5-20万 | 2-4个月 |
| 二类有源设备（如监护仪） | 10-50万 | 3-6个月 |
| 三类高风险植入物 | 20-100万 | 6-12个月 |
| AI软件（SaMD） | 10-30万 | 2-4个月 |

> ⚠️ 区间仅供参考，具体看产品复杂度、测试项多少、机构排期。

## 常见坑

1. **没选对机构**——机构资质范围不覆盖你的产品，报告不认
2. **漏了关键测试项**——注册时才发现，要补测，耽误2-3个月
3. **产品没定型就送检**——检测中途改设计，报告要重做
4. **同时找多个机构**——不同机构方法差异，结果不一致
5. **没留样机**——补测时找不到同批次样品
6. **只看价格不看周期**——便宜机构排期长，反而耽误注册
7. **忽略包装/运输测试**——货架期、运输包装是必交的
