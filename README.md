## 这是什么？

注册申报前必须做第三方检测，但很多人不知道：这个产品到底要做哪些检测项目？找CNAS还是CMA？大概多少钱、多久能出报告？

这个Skill帮你：
- 列清楚必做的检测项目清单
- 说明需要什么资质的机构
- 估算费用和周期
- 提醒常见踩坑点
